Day 20 – User Validation



Objective



Test whether a new user can understand and use the current Logic Leak 2.0 workflow with minimal guidance.



Test Flow



Login → Challenge → Identify the Vulnerability → Explain → Fix → Earn XP → Progress → Next Challenge



What I Will Observe



\* Can the user understand the challenge instructions?

\* Can the user identify the vulnerability?

\* Can the user understand the explanation?

\* Can the user understand the expected fix?

\* Is the XP and progress system clear?

\* Can the user move to the next challenge without confusion?



User Feedback



For each tester, record:



\* What was easy?

\* What was confusing?

\* Where did they get stuck?

\* Which instruction was unclear?

\* What feature did they expect?



Validation Goal



The purpose of this test is to identify usability problems before adding major new features.



Result



Issues found during testing will be converted into development tasks for the next stage of Logic Leak 2.0.



Next Step



Improve the current user experience based on actual feedback and then continue product development.
