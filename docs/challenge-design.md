# Logic Leak 2.0 - Challenge Design

## Overview

Each Logic Leak challenge is designed to simulate a simplified secure code-review scenario.

Users must identify a vulnerability, understand why it exists, propose a secure fix, and consider an additional edge case.

## Three-Tier Structure

### Tier 1 - Identify

The user identifies the main security vulnerability in the provided code.

**Points:** 30

### Tier 2 - Explain + Fix

The user explains why the vulnerability exists and describes an appropriate secure fix.

**Points:** 30

### Tier 3 - Edge Case

The user identifies an additional security concern, unexpected input, or boundary condition.

**Points:** 40

## Scoring

Each challenge is worth 100 points.
